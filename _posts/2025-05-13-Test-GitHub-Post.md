This is a test GitHub post, it's only created and posted to test out the hidden flags. It has all 3 hidden flags applied, as well as a GitHub tag.

1. hidden-1 means hidden from recent posts and won't appear on the homepage on the blog unless explicitly linked to elsewhere. It will be visible in the all posts list/page and tag lists if it has other tags.
2. hidden-2 means hidden from the all posts list/page, in most cases it would be combined with hidden-1. This post would only be visible in any tag pages if it has other tags, or if again, it's explicitly linked elsewhere.
3. hidden-3 means hidden from tag lists, so whether it has every tag imaginable, if hidden-3 is also tagged, it shouldn't appear in any of the tag lists. This tag will most likely be combined with the other two hidden tags for secret posts or just to hide articles.
